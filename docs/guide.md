# Kaze 主题使用指南

> 适用于 Kaze v1.4.x，要求 Halo >= 2.22.0

## 快速开始

### 安装

**方式一：应用市场安装（推荐）**

在 Halo 后台「应用市场」搜索「Kaze」，点击安装即可。

**方式二：手动上传**

1. 前往 [GitHub Releases](https://github.com/webrong/halo-theme-kaze/releases) 下载最新版本的 ZIP 包
2. 进入 Halo 后台 → 外观 → 主题 → 右上角「安装」→「上传」
3. 选择下载的 ZIP 文件，点击安装

**方式三：远程下载**

进入 Halo 后台 → 外观 → 主题 → 右上角「安装」→「远程下载」，输入：

```
https://github.com/webrong/halo-theme-kaze/releases/latest/download/theme-kaze.zip
```

### 启用

安装完成后，在主题列表中找到 Kaze，点击「启用」。

`[截图：主题管理列表，Kaze 卡片上的启用按钮]`

### 基础配置

启用后点击主题卡片进入「主题设置」，按需配置各分组。

`[截图：主题设置页面，左侧设置分组菜单]`

## 首页设置

### Hero 轮播

首页顶部支持两种模式：

- **轮播模式**：添加多张幻灯片，自动轮播切换
- **单图模式**：不添加幻灯片时，使用单张背景图

`[截图：首页 Hero 轮播效果]`

**配置路径**：主题设置 → Hero 轮播

| 设置项 | 说明 |
|--------|------|
| Hero 标题 | 轮播区域主标题 |
| Hero 副标题 | 标题下方说明文字 |
| Hero 徽章文字 | 左上角小标签，如「Halo · 个人博客」 |
| Hero 背景图片 | 单图模式的背景图（轮播模式无效） |
| 轮播幻灯片 | 最多 10 张，每张含图片、标题、副标题、徽章、CTA 按钮 |

**幻灯片字段说明**：

`[截图：添加幻灯片的表单界面]`

| 字段 | 必填 | 说明 |
|------|------|------|
| 幻灯片图片 | 是 | 建议尺寸 1920×1080，支持 JPG/PNG/WebP |
| 徽章文字 | 否 | 左上角标签，如「推荐」「新文章」 |
| 标题 | 是 | 幻灯片主标题 |
| 副标题 | 否 | 标题下方补充说明 |
| CTA 按钮标签 | 否 | 行动按钮文字，如「阅读全文」 |
| CTA 按钮链接 | 否 | 按钮跳转地址 |

### 文章列表布局

**配置路径**：主题设置 → 首页设置

- **网格卡片**（默认）：两列卡片，展示封面图、分类、标题、摘要、日期
- **列表模式**：单列紧凑布局，适合文字为主的博客

`[截图：网格模式 vs 列表模式对比]`

### 侧边栏

**配置路径**：主题设置 → 首页设置 → 显示侧边栏

开启后首页右侧显示侧边栏，包含：

- **作者卡片**：头像、昵称、简介、社交图标
- **分类列表**：所有分类及文章数
- **标签云**：所有标签的彩色胶囊
- **最近文章**：最新 5 篇文章

`[截图：侧边栏四个组件的效果]`

侧边栏内容来源：

- 作者信息 → 主题设置 → 个人信息
- 社交图标 → 主题设置 → 社交链接（显示 GitHub、Twitter、Email、Bilibili、个人网站 5 个）

## 页面模板

Kaze 提供 4 个自定义页面模板，创建独立页面时在右侧「自定义模板」下拉菜单中选择。

`[截图：创建页面时选择自定义模板的下拉菜单]`

### 关于页

**模板**：`page_about`

双栏布局，左侧个人资料卡片，右侧内容区。

`[截图：关于页完整效果]`

展示内容包括：

| 区域 | 数据来源 |
|------|----------|
| 头像、昵称、简介 | 主题设置 → 个人信息 |
| 统计（文章数/瞬间数/照片数） | 自动统计 |
| 社交链接（全部 10 个平台） | 主题设置 → 社交链接 |
| 关于我 | 页面正文内容（优先），或主题设置中的「关于我」 |
| 兴趣标签 | 主题设置 → 兴趣标签（逗号分隔） |
| 里程碑时间线 | 主题设置 → 里程碑时间线 |
| 技能雷达图 | 主题设置 → 技能雷达图（最多 6 项） |
| 当前装备 | 主题设置 → 设备展示（仅显示「正在使用」状态） |
| 更新日志 | 主题设置 → 网站更新日志 |

**创建步骤**：

1. 后台 → 页面 → 新建页面
2. 标题填「关于」
3. 右侧「自定义模板」选择「关于页面」
4. 在页面编辑器中写「关于我」的内容（可选，留空则使用主题设置中的文字）
5. 发布

### 摄影页

**模板**：`page_photography`

瀑布流相册展示，依赖 **Photos 图库插件**。

`[截图：摄影页效果，展示相册卡片网格]`

**创建步骤**：

1. 确保已安装 [Moments / Photos 插件](https://www.halo.run/store/apps/app-SnwWD)（Halo 官方图库管理插件）
2. 在插件管理中创建相册分组和相册，上传照片
3. 后台 → 页面 → 新建页面
4. 标题填「摄影」
5. 右侧「自定义模板」选择「摄影页面」
6. 别名建议设为 `photography`
7. 发布

**未安装图库插件时**：摄影页会自动 fallback，展示文章封面图组成的照片墙。

### 瞬间页

**模板**：`page_moments`

三栏时间线布局，展示动态、照片、评论，依赖 **Moments 瞬间插件**。

`[截图：瞬间页效果，展示时间线动态卡片]`

**创建步骤**：

1. 确保已安装 Moments 瞬间插件
2. 后台 → 页面 → 新建页面
3. 标题填「瞬间」
4. 右侧「自定义模板」选择「瞬间页面」
5. 别名建议设为 `moments`
6. 发布

**未安装瞬间插件时**：会自动 fallback，展示最近文章摘要作为动态卡片。

### 装备页

**模板**：`page_gear`

卡片网格展示设备，数据来自主题设置。

`[截图：装备页效果，展示设备卡片]`

**创建步骤**：

1. 先在主题设置 → 设备展示中添加设备
2. 后台 → 页面 → 新建页面
3. 标题填「装备」
4. 右侧「自定义模板」选择「设备页面」
5. 别名建议设为 `gear`
6. 发布

## 主题设置详解

### 个人信息

`[截图：个人信息设置表单]`

| 设置项 | 说明 |
|--------|------|
| 头像 | 用于侧边栏和关于页的头像 |
| 显示名称 | 侧边栏和关于页的昵称 |
| 一句话简介 | 侧边栏和关于页的简介文字 |
| 关于我 | 关于页的「关于我」区域文字（如果页面正文为空则使用此内容） |
| 兴趣标签 | 逗号分隔，如「摄影,编程,旅行,咖啡」 |
| 里程碑时间线 | 最多 20 条，年份 + 描述，用于关于页 |
| 技能区副标题 | 技能雷达图上方的说明文字 |
| 技能雷达图 | 最多 6 项，名称 + 分值(0-100)，关于页渲染为六边形雷达图 |
| 网站更新日志 | 最多 50 条，日期 + 内容，关于页渲染为时间线 |

### 社交链接

支持 10 个平台，在侧边栏（显示 5 个）和关于页（显示全部 10 个）展示。

`[截图：社交链接设置表单]`

| 平台 | 设置项 | 格式 |
|------|--------|------|
| GitHub | URL | `https://github.com/你的用户名` |
| Email | 邮箱 | `your@email.com` |
| Twitter / X | URL | `https://x.com/你的用户名` |
| Bilibili | URL | `https://space.bilibili.com/你的UID` |
| 微博 | URL | `https://weibo.com/你的ID` |
| 知乎 | URL | `https://www.zhihu.com/people/你的ID` |
| 微信二维码 | 图片上传 | 上传二维码图片，关于页点击可放大 |
| YouTube | URL | `https://youtube.com/@你的频道` |
| 小红书 | URL | `https://www.xiaohongshu.com/user/profile/你的ID` |
| 个人网站 | URL | `https://your-site.com` |

### 页脚设置

`[截图：页脚效果]`

| 设置项 | 说明 |
|--------|------|
| 自定义页脚文字 | 版权声明等，如「© 2024 All rights reserved.」 |

### 设备展示

在装备页展示的设备列表。

`[截图：设备展示设置表单]`

每个设备包含：

| 字段 | 说明 |
|------|------|
| 设备名称 | 如「MacBook Pro 14"」 |
| 品牌/型号 | 如「Apple M3 Pro」 |
| 设备图片 | 上传设备照片 |
| 规格 | 分号分隔，如「18GB RAM;512GB SSD;Space Black」，每项渲染为独立标签 |
| 一句话评价 | 如「性能怪兽，安静且可靠」 |

## 插件适配

Kaze 自动适配以下插件，安装对应插件后相关页面自动生效。

### 必装插件

| 插件 | 功能 | 安装方式 |
|------|------|----------|
| Comment Widget | 文章/页面评论 | Halo 内置，一般无需额外安装 |
| Search Widget | 全站搜索 | Halo 内置 |

| 插件 | 功能 | 安装后的效果 |
|------|------|-------------|
| [Photos 图库](https://www.halo.run/store/apps/app-SnwWD) | 照片管理 | 摄影页展示相册分组和照片 |
| [Moments 瞬间](https://www.halo.run/store/apps/app-SnwWD) | 动态发布 | 瞬间页展示时间线动态 |
| [Links 链接管理](https://www.halo.run/store/apps/app-XqAHj) | 友情链接 | 友链页展示分组和链接卡片 |
| [SEO Tools](https://www.halo.run/store/apps/app-MHSub) | SEO 优化 | 自动生成 sitemap、meta 标签，与主题内置 SEO 协同工作 |

### 高级适配

| 插件/功能 | 说明 |
|-----------|------|
| [Docsme 文档](https://www.halo.run/store/apps/app-DZhSR) | 文档管理插件，安装后自动支持文档阅读、目录导航、项目列表三个页面 |
| Halo 商业版商城 | 商业版商城功能，安装后自动支持商品列表、商品详情、购物车、结算、支付五个页面 |

**Docsme 文档页面说明**：

安装 Docsme 插件后，主题自动提供三个文档页面模板，无需手动创建页面：

| 页面 | 路由 | 说明 |
|------|------|------|
| 文档项目列表 | `/docs` | 展示所有文档项目 |
| 文档目录 | `/docs/{group}/{slug}` | 展示文档目录树 |
| 文档阅读 | `/docs/{group}/{slug}/{child}` | 文档内容阅读页 |

**商城页面说明**：

使用 Halo 商业版并启用商城功能后，主题自动提供五个商城页面模板：

| 页面 | 路由 | 说明 |
|------|------|------|
| 商品列表 | `/shop/products` | 所有商品 |
| 商品详情 | `/shop/product/{id}` | 单个商品 |
| 购物车 | `/shop/cart` | 购物车 |
| 结算 | `/shop/checkout` | 下单结算 |
| 支付 | `/shop/payments` | 支付页面 |

## 功能特性

### 文章详情页

`[截图：文章详情页三栏布局]`

- **阅读进度条**：文章顶部细线显示阅读进度
- **自动目录（TOC）**：左侧栏自动生成 h2/h3 目录，滚动时高亮当前章节
- **图片灯箱**：点击文章内图片弹出放大查看，支持左右切换和键盘导航
- **代码块增强**：显示语言标签 + 一键复制按钮
- **点赞功能**：右侧操作栏，带弹跳动画
- **分享功能**：一键复制文章链接
- **相关文章**：文章底部展示相关推荐
- **评论系统**：底部集成 Halo 评论组件

### 暗色模式

- 手动切换：点击导航栏右侧的月亮/太阳图标
- 自动检测：首次访问时读取系统偏好
- 全站适配：包括文章、页面、代码块、灯箱、页脚等所有组件

`[截图：亮色模式 vs 暗色模式对比]`

### SEO

主题内置完整 SEO 方案，无需额外配置即可生效：

- **Open Graph** — `og:type`、`og:title`、`og:description`、`og:image`、`og:url`、`og:site_name`、`og:locale`
- **Twitter Cards** — `summary_large_image` 格式
- **JSON-LD 结构化数据** — 文章（BlogPosting）、作者（Person）、面包屑（BreadcrumbList）等
- **Canonical URL** — 每个页面自动设置规范链接
- **robots** — 归档/分类/标签/搜索页自动 `noindex`
- **SEO Tools 协同** — 安装 SEO Tools 插件后自动切换为补充模式，避免重复标签

### 响应式设计

三组断点适配不同设备：

| 断点 | 适配场景 |
|------|----------|
| ≤ 480px | 手机竖屏 |
| ≤ 768px | 手机横屏 / 平板竖屏 |
| ≥ 1024px | 桌面端 |

移动端特性：
- 汉堡菜单折叠导航
- 文章 TOC 移至文章顶部折叠
- 侧边栏隐藏
- 灯箱缩略图条隐藏

### 返回顶部

全站通用，滚动超过一定距离后右下角出现圆形按钮，点击平滑回顶。移动端自动缩小尺寸适配。

## 常见问题

### 摄影页显示的不是相册？

确保已安装 **Photos 图库插件**，并在插件管理中创建了相册和上传了照片。未安装插件时，摄影页会 fallback 展示文章封面图。

### 瞬间页没有数据？

确保已安装 **Moments 瞬间插件**，并在后台发布了一些瞬间内容。

### 友链页显示空白？

确保已安装 **Links 链接管理插件**，并在后台添加了链接组和链接。同时创建一个独立页面，选择自定义模板「友情链接」。

### 文章目录没有显示？

目录（TOC）从文章的 `h2` 和 `h3` 标题自动生成。如果文章没有使用标题层级，目录区域会自动隐藏。

### 暗色模式不生效？

点击导航栏右侧的月亮图标手动切换。主题会记住用户偏好到 localStorage，下次访问自动应用。

### 商城页面显示 Halo 默认模板？

确保使用的是 Halo 商业版并已启用商城功能。主题版本需 >= 1.4.0。

### 关于页的「关于我」区域是空的？

在主题设置 → 个人信息 → 关于我 中填写内容，或在关于页面的编辑器中直接写入正文内容（优先使用页面正文）。
